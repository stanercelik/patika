# Yolum faz illüstrasyonları

Bu üç görsel, onboarding sonrası `Yolum` ekranında gerçek program fazlarına
bağlı sessiz boşluk işaretleri olarak kullanılır. Kırık beyaz, dokulu şerit dili
mevcut C1/C2 illüstrasyon ailesini sürdürür. Görseller dekoratiftir ve VoiceOver
ağacına girmez.

- `journey-relief-source.png`: yerleşme ve yükü hafifletme.
- `journey-practice-source.png`: fark etme, beceri ve davranış fazlarının ortak
  pratik dili.
- `journey-closing-source.png`: kutlama olmadan kapanış ve geri dönüş.

Uygulamadaki 2x kopyalar `MyApp/Assets.xcassets/Journey/` altında 512 piksel uzun
kenara küçültülmüştür. Kaynak görseller yerinde tutulur.

Üretim: Codex built-in image generation. Ortak prompt sınırları: transparan
zemin, yalnızca sıcak kırık beyaz ve soğuk gri öz gölgeler, ince keçe-kâğıt
dokusu, insan/yüz/metin/ikon/emoji/yıldız/ödül/ok/merdiven/sonuç grafiği yok.
